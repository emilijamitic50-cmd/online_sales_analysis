# Online Sales Analysis

Python projekat za upravljanje proizvodima, inventarom i korpom kupca.

## Struktura projekta
- `product.py` – klasa Product (name, price, quantity), prikaz info i ažuriranje količine
- `product_manager.py` – klasa ProductManager (dodavanje, prikaz proizvoda, ukupna vrednost inventara, uklanjanje po imenu)
- `cart.py` – klasa Cart (dodavanje proizvoda u korpu, prikaz korpe, ukupna vrednost za naplatu)
- `main.py` – demonstracija funkcionalnosti sistema

## Funkcionalnosti
- Dodavanje proizvoda u inventar
- Prikaz dostupnih proizvoda
- Računanje ukupne vrednosti inventara
- Uklanjanje proizvoda po nazivu
- Dodavanje proizvoda u korpu i prikaz sadržaja korpe
- Računanje ukupne vrednosti korpe

## Pokretanje
```bash
python main.py
